# Android builds

The wrapper is generated by `npm run android:prepare` from `scripts/android.mjs` and `android-app/MainActivity.java`. APP_URL must be your deployed HTTPS URL. The application ID defaults to `com.sanchitduggal.siterequisitions`; set APP_ID before the first release if a different value is needed, then never change it. Minimum SDK 26. Compile/target SDK 36 (available stable package verified against Google SDK repository). Java 21 and an installed Android SDK are required.

```sh
npm ci
APP_URL=https://your-app.workers.dev npm run android:prepare
cd android-app/android
./gradlew assembleDebug
```

Debug builds are for testing only. A distributable release requires a signing key. Generate it with the JDK's keytool, which prompts for passwords:

```sh
keytool -genkeypair -v -keystore release.jks -alias site-requisitions -keyalg RSA -keysize 3072 -validity 10000
```

**Back up the keystore, alias and passwords securely outside this repository. Losing them prevents updates over existing installations. Never commit them.** Store KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD in GitHub Actions secrets. Set APP_URL as a repository variable. Run build-apk manually or push a version tag. The workflow assembles and verifies the signed APK, uploads an artifact, and publishes a release asset on a tag. versionName comes from package.json; versionCode comes from the workflow run number.

The native wrapper denies cleartext app traffic and keeps navigation inside the configured HTTPS origin. External HTTP(S) links open in the system browser. Failed top-level loads show a native Retry page. Hardware back is handled by the App plugin: nested screens go back; the root exits. Report files are written to the app cache and shared through the Android file provider. No broad storage permission is needed.

Before distribution complete DEVICE_TEST_CHECKLIST.md on API 26 and current Android, and verify `apksigner verify --verbose`. Optional Play distribution requires a separate Google Play developer account and review; it is not part of this free APK-sharing setup.

Android 8 or newer requires Android System WebView/Chrome 108 or newer. An obsolete engine shows a native update message with a Play Store link. Update the system engine and reopen the app. The Android 8 emulator check verifies that message, not app workflows on an obsolete engine.
